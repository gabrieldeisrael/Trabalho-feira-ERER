# Regra de Log (OBRIGATÓRIO)

Este projeto manipula arquivos rodando no Render (Plano Free). Nunca adicione comentários dentro dos arquivos JSON.

1. **Antes de agir:** Leia as primeiras linhas do arquivo `AI_LOG.md` na raiz para entender as últimas alterações feitas no projeto.
2. **Ao concluir qualquer alteração:** Adicione uma nova linha no **topo** da lista em `AI_LOG.md` seguindo estritamente este formato (sem negrito, sem data, apenas texto direto separado por barra vertical):
   `[Nome da IA] | [Nome ou Usuário do Github ou Apelido do Integrante] | [Resumo curto e direto do que foi feito e em quais arquivos]`

Exemplo:
`Gemini | João | Mesclei 2 arquivos e substitui o placeholder em dados.json`

3. **Todas as páginas precisam ter o mesmo estilo geral. Mas pode deixar a interface de moderamento e aprovação mais básica sem necessidade de deixar bonito**
